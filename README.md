# Object Oriented Programming CA1 - Group A

## FoodBridge
FoodBridge is a Java application developed in NetBeans. It contains food donations, food requests and volunteering.

## Group Development
Group members develop their features on separate Git branches and completed work is integrated into a single NetBeans project and pushed to main.
